# Drelva — Homebrew

Drelva is a small cross-platform command-line utility.

## Install

```bash
brew tap dsongtn/drelva
brew install drelva
drelva version
drelva doctor
```

Homebrew is not included with macOS. Release files are pinned to SHA-256 checksums.

## Remove

```bash
brew uninstall drelva
brew untap dsongtn/drelva
```

Version 0.1.1 is a development preview. The macOS PKG is not notarized.
